For common items that are requested but not yet included in the script; welcome to the help section.

These are simple remedy scripts for changes requested after running the script.

*WINDOWS INSIDERS

If you are on the Windows Insider Program to get preview release builds through Windows Updates:  
The telemetry & service changes, among other items in TBOKwinOptimizer will cause Insider Preview updates to stop because those data collection services and settings are stopped/OFF.

The file: TBOK-Restore-Windows-Insider.bat will restore those settings to the Microsoft required status. Download & Run the file, then reboot your pc and set your insider settings again.
Running a Windows Insider Build means Microsoft Gets Additional usage information about your system, what's installed, and how you use your computer, among other things.
Choosing to run an Insider Preview Build means those extra services and settings have to be enabled because you are volunteering data to Microsoft.  It's a trade-off.



*LOG ON / LOG OFF / STARTUP / SHUTDOWN SCREEN DETAILS

If you prefer the simple "Starting Windows" and "Shutting Down" messages instead of actually seeing what the computer is doing during those phases.

The file TBOK-Restore-Simple-Logon.bat will put them back to windows standard messages. Download & Run the file, the change is immediate, no need to reboot.
